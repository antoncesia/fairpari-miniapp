# Закрытый прототип Telegram Mini App

Кликабельный прототип Mini App. Страница защищена паролем: в репозитории лежит только зашифрованная версия (AES-256-GCM, ключ из пароля через PBKDF2-SHA256), расшифровка идёт в браузере после ввода пароля. Без пароля содержимое прототипа не прочитать — ни на странице, ни в коде репозитория.

- `index.html` — экран ввода пароля и зашифрованный прототип.
- `tools/gate.html` — шаблон экрана входа.
- `tools/encrypt.py` — сборка `index.html` из исходника.
- `bot/bot.py` — минимальный бот: отвечает на `/start` кнопкой, которая открывает Mini App, и пробрасывает реф-метку.

Исходник `src/index.plain.html` и файл с паролем хранятся только локально и в репозиторий не попадают (см. `.gitignore`).

## Как обновить прототип

```bash
pip install cryptography
PROTO_PASSWORD_FILE=../fairpari-miniapp.password.txt python3 tools/encrypt.py
git add index.html && git commit -m "Обновить прототип" && git push
```

Чтобы сменить пароль, впишите новый последней строкой в файл с паролем и пересоберите. Сохранённый на устройствах старый пароль перестанет подходить, и экран входа появится снова.

## Как подключить к боту

1. В @BotFather: `/mybots` → бот → **Bot Settings → Configure Mini App** → URL страницы GitHub Pages.
2. **Bot Settings → Menu Button** → тот же URL, текст кнопки «Играть».
3. По желанию: `/newapp` — прямая ссылка вида `t.me/<бот>/<app>?startapp=ref_339`.

## Запуск бота

```bash
pip install aiogram
BOT_TOKEN=... APP_URL=https://<аккаунт>.github.io/<репозиторий>/ python bot/bot.py
```

Токен бота не коммитить и не пересылать в чатах — только через переменную окружения.

## Важно

Это прототип: регистрация, ставки и депозиты имитируются, реальные данные никуда не отправляются.
